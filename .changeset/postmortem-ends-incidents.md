An incident with a postmortem now counts as ended everywhere. On public status pages it moves from active incidents to the resolved history, and the incident list treats it as closed. If the same monitor goes down again, a new incident opens instead of the outage going unrecorded. On the incident page you can now edit a postmortem after adding it, and updates close once a postmortem exists, as they do for a resolved incident. The API reference now lists `postmortem` as an incident status.
